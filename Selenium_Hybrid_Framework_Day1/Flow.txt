Page Object Model

- We locate Object by using @FindBy() or @FindBys() annotation

- FindBy() Annotation used to Locate Single Object

- FindBys() Annotation used to Locate Multiple Objects 

- We Initialize these elements by using PageFactory.initElements(driver,this) keyword in constructor
